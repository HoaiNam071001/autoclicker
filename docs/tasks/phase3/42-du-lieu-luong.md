- [ ] **42. Dữ liệu & luồng** *(người dùng yêu cầu, 2026-10-20 – làm ngay sau 41, trước 43; làm được trên Mac)* – Bớt node Chờ cố định (chờ tới khi màn hình xong việc), lặp theo dữ liệu thật (danh sách chỗ thấy, dòng CSV, mảng JSON) và xử lý giá trị đọc được (tính toán, regex, định dạng) ngay trong flow.
  - **Chốt 2026-10-20:** thứ tự 3 → 1 + 2 → 5 (G1 → G2 + G3 → G4). **Mỗi việc một node** (xem `decisions.md` – node mới của 42 / 43, không gộp nhiều việc vào một node có ô chọn thao tác). Node thêm theo skill `add-node-type`, mỗi node có mẫu thử (33) + mô tả N0.
  - [x] G1. **Chờ màn hình đứng yên / thay đổi** (`waitScreen`): chụp một vùng (vùng kịch bản / vùng cố định / khung output node trước như node Chụp màn hình) mỗi `intervalMs`; `waitMode` stable = khác biệt giữa 2 lần chụp ≤ ngưỡng trong `stableMs` liên tục (trang tải xong, hiệu ứng dừng) / change = khác ảnh lúc bắt đầu node quá ngưỡng (đã có phản hồi sau click). Hết `timeoutMs` → cổng fail. Output `ms` (thời gian chờ), `diff` (%). So sánh trên ảnh xám thu nhỏ (`vision`, hàm thuần có test), bỏ qua vùng nhấp nháy nhỏ (con trỏ chữ) bằng ngưỡng % điểm ảnh đổi
    - Đã làm 2026-10-21: trường `waitMode` / `stableMs` (1000) / `diffPct` (1 %, số nguyên) + dùng lại `shotArea` / `display` / `shotRect` / `imageFrom` của Chụp màn hình (`ShotAreaField`, `script/shotcheck.go`); so ảnh: xám thu nhỏ rộng ≤ 320 px, điểm lệch > 20/255 mới tính (`vision/screendiff.go`) – con trỏ chữ ~0,01 %. Hết giờ = lỗi `timeout`, `detail.diff`. Không thêm trường ghim (Pinnable như Chờ pixel). Mẫu `cho-man-hinh` + trang `loading.html`
  - [ ] G2. **Lặp qua danh sách** (`forEach`): nguồn `items` – mảng JSON từ biến (`{{n3.output.json.items}}`, output danh sách của G3), các dòng của một chữ, file CSV / xlsx (dòng đầu là tên cột → `{{n4.output.item.<cột>}}`). Cổng `item` (mỗi phần tử một lần, output `item`, `index`, `count`) và `done` (hết danh sách). Cạnh quay lại từ cuối thân vòng vào chính node (giống Đếm): engine giữ con trỏ theo lượt vào node, chạy lại từ đầu khi đã `done`. Chặn lặp vô hạn 10 000 node / vòng giữ nguyên. Xem trước (F6): menu Nhánh chọn đi 1 lượt / tới `done`
    - Mục *CSV mỗi dòng một lần* của 28 còn lại phần *chạy cả kịch bản theo từng dòng* (form Chạy); trong flow thì dùng node này
  - [ ] G3. **Tìm tất cả** (`findAll`): như Chờ ảnh / chữ / phần tử (dùng chung trường tìm: `findBy`, ảnh mẫu, `findText`, `selectors`, `searchArea`) nhưng trả **mọi** chỗ khớp: output `count`, `items` [{x, y, w, h, score, text}] xếp theo đọc (trên → dưới, trái → phải), `min` / `max` số lượng để đi cổng fail. Phần tử (AX / UIA) và web (Chrome thường) đều qua `element`; chồng lấn (NMS) gộp chỗ trùng của tìm ảnh. Overlay Thử tìm vẽ khung + số thứ tự
  - [ ] G4. **Biểu thức / xử lý chữ** – hai node (mỗi việc một node):
    - [ ] G4a. **Tính toán** (`calc`): biểu thức `{{a}} * 2 + 1`, `round / floor / min / max / abs`, so sánh + và / hoặc → output `value` (số / true-false). Bộ tính tự viết (không `eval`, không thư viện nặng), cùng hàm ở Go (engine) và TS (xem trước output trong inspector), test chung `testdata/calc.json`
    - [ ] G4b. **Xử lý chữ** (`textOp`): `op` regex (lấy nhóm / mọi chỗ khớp → mảng), tách theo ký tự, thay, cắt khoảng trắng, hoa / thường, bỏ dấu, lấy số (`1.234.567 đ` → `1234567`, dùng lại hàm *lấy số* của 37 E4), định dạng số / ngày. Output `text` (+ `items` khi ra mảng – nối thẳng vào G2)
  - [ ] G5. Mẫu thử + sân thử: trang danh sách có nút *Thêm* lặp lại + bảng giá (G3 → G2 → click từng nút; đọc giá → G4b lấy số → G4a so ngưỡng → Nếu); trang tải chậm có spinner (G1 thay Chờ 3 s)
