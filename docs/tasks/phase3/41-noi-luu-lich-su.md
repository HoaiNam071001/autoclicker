# 41. Nơi lưu kịch bản / ảnh chụp + xoá lịch sử

- [ ] **41. Nơi lưu kịch bản / ảnh chụp + xoá lịch sử** *(người dùng yêu cầu, 2026-10-20 – làm ngay, trước 40 O0–O3 / 31c; làm được trên Mac)* – Người dùng tự chọn thư mục lưu kịch bản (tay / AI) và ảnh chụp trong Cài đặt; xoá được từng mục hoặc tất cả trong lịch sử chạy và danh sách *Mở gần đây*.
  - **Chốt 2026-10-20:** thư mục người dùng nhìn thấy đặt tên **Auto Clicker** (Documents/Auto Clicker cho kịch bản, Pictures/Auto Clicker cho ảnh); thư mục cấu hình giữ `autoclicker` (AppData / Application Support), không đổi. Thư mục ảnh trong Cài đặt chỉ là **mặc định** cho node Chụp màn hình để trống `saveDir` – node đã đặt thư mục riêng thì giữ. Kịch bản đã có file thì *Lưu* vẫn ghi tại chỗ cũ.
  - [ ] L1. **Thư mục chuẩn đúng trên Windows** – lấy Documents / Pictures qua `SHGetKnownFolderPath` (`FOLDERID_Documents`, `FOLDERID_Pictures`) thay cho ghép `home + "Documents"`, để máy có OneDrive chuyển thư mục vẫn đúng; macOS / khác giữ `~/Documents`, `~/Pictures`. Hàm chung trong `internal/store` (vd `knownfolder_windows.go` + bản thường), `store.ScriptsDir` và `engine/shot.go` (`shotPath`) cùng dùng. Đổi `Pictures/autoclicker` → `Pictures/Auto Clicker`
  - [ ] L2. **Cài đặt Lưu trữ** – `Settings.Storage { scriptsDir, aiScriptsDir, shotsDir }` (trống = mặc định ở L1). Hộp Cài đặt chia **tab** (Chung / Lưu trữ / API / MCP…) vì một cột đã dài; tab *Lưu trữ*: 3 ô thư mục, mỗi ô có nút *Chọn…* (hộp thoại chọn thư mục), *Mở* (Finder / Explorer), *Về mặc định*; hiện đường dẫn mặc định khi để trống
    - Kịch bản lưu tay: hộp thoại *Lưu* lần đầu (`SaveScriptAs` khi `path == ""`) mở sẵn `scriptsDir`; *Mở* kịch bản cũng mở ở đó
    - Kịch bản AI: `ScriptsDir()` (MCP `create_script`, bản sao khi AI sửa kịch bản đang dở) đọc `aiScriptsDir`; mặc định trùng `scriptsDir`
    - Ảnh: engine nhận thư mục ảnh mặc định qua tuỳ chọn chạy (không đọc settings trong engine); `saveDir` trống → `shotsDir`
    - Thư mục không ghi được (xoá mất, ổ rút ra) → lúc lưu báo lỗi rõ, gợi ý về mặc định; không tự lặng lẽ đổi chỗ
  - [ ] L3. **Xoá lịch sử chạy** – hộp Lịch sử (`library/RunsDialog`): xoá một lần chạy (file `<id>.json` + `<id>-*.png`), *Xoá hết* của kịch bản đó (hỏi xác nhận). `store.DeleteRun` / `store.ClearRuns` có test; id kiểm tra bằng `safeName` (không xoá ra ngoài thư mục runs)
  - [ ] L4. **Xoá *Mở gần đây*** – Thư viện: nút ✕ từng mục (dùng `RemoveRecent` có sẵn) + *Xoá danh sách*; chỉ bỏ khỏi danh sách, không xoá file kịch bản
  - Chuẩn bị cho MCP: `list_scripts` / `create_script` đọc thư mục từ `aiScriptsDir`; guide / mô tả node Chụp màn hình sửa câu *trống = Pictures/autoclicker* thành *trống = thư mục ảnh trong Cài đặt*
  - Kiểm tra tay: ghi vào [checks.md](../checks.md) khi xong code – đổi 3 thư mục trong Cài đặt → Lưu lần đầu mở đúng chỗ, AI tạo kịch bản vào đúng chỗ, node Chụp màn hình để trống ra đúng chỗ; Windows có OneDrive → file vào Documents / Pictures trong OneDrive; xoá một / tất cả lần chạy, xoá mục / cả danh sách Mở gần đây
