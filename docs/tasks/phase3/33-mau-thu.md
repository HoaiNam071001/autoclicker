# 33. Kịch bản mẫu để test + sân thử

- [ ] **33. Danh sách kịch bản mẫu để test** *(người dùng yêu cầu, 2026-10-18 – làm trước 25d D1)* – Nút **Mẫu thử** ở Thư viện (cạnh Mới / Mở) mở hộp thoại danh sách kịch bản mẫu đơn giản, mỗi mẫu test một / vài loại bước (click nhiều lần, kéo thả, chờ chữ…), **không dính ngữ cảnh** (không đăng nhập, không tài khoản thật). Chọn mẫu → mở **bản sao chưa lưu** trong trình soạn (như bấm Mới) để xem / sửa / Chạy; mẫu gốc không đổi.
  - **Nguyên tắc (người dùng chốt 2026-10-18):**
    - Mỗi loại bước có **ít nhất 1 mẫu**; bước mới sau này (web DOM 25d, focus cửa sổ 26…) **làm xong phải thêm mẫu** – test Go chặn: loại bước trong `StepTypeDocs` chưa có mẫu → đỏ
    - Nhiều mẫu theo nhiều kiểu web app khác nhau (form, shop, chat, kanban, game, feed, quiz…), lọc được theo loại bước + kiểu app
    - Trang đích chủ yếu là **sân thử cục bộ** (trang HTML giả lập kèm app, offline, không đổi theo thời gian, tự hiện kết quả: đã click mấy lần, kéo từ đâu tới đâu…) + **vài mẫu web thật** công khai không cần đăng nhập (Wikipedia, Google…) gắn nhãn *web thật* (có thể hỏng khi trang đổi giao diện)
    - Bước theo toạ độ (click, double, giữ, kéo): trang sân thử cho các bước này là **vùng lớn nhận ở đâu cũng được** (bảng đếm click, bảng vẽ) → chạy được ở mọi vị trí cửa sổ. Mẫu cần trúng đúng nút thì tìm bằng chữ / ảnh trước (Chờ chữ → Click theo ảnh); xong 25d thêm mẫu bấm theo DOM
  - **Chi tiết kỹ thuật (tự chọn):**
    - Go package `internal/samples`: mẫu là file JSON kịch bản thường + metadata (`id`, tên, mô tả, loại bước test, kiểu app, độ khó, trang sân thử, `real` = web thật) nhúng bằng `embed`; trang sân thử `pages/*.html` cũng nhúng. Không phụ thuộc UI → MCP (31) dùng lại được làm ví dụ cho AI
    - Trang sân thử: lúc mở mẫu, Go ghi các trang ra `ConfigDir/sandbox/` (ghi đè – luôn khớp bản app) và thay `{{sandbox}}` trong `target` của bước Mở bằng đường dẫn `file://` thật. Chọn `file://` thay vì server HTTP cục bộ: không chiếm cổng (D0 gặp cổng 9333 bị giữ), bản sao đã lưu vẫn mở được ở lần chạy sau; CDP (25d) đọc được `file://`
    - Trang sân thử chỉ HTML + CSS + JS thuần trong một file, chữ to rõ (OCR đọc được), màu tương phản (chờ màu pixel), không tải gì từ mạng
