# 44. Thử trang trên Chrome của app + ưu tiên node cho AI

- [ ] **44. Thử trang trên Chrome của app + ưu tiên node cho AI** *(người dùng yêu cầu 2026-10-21 – làm ngay, trước 42)* – Trước khi soạn kịch bản cho một trang (vd trang game A), người dùng / AI mở thử trang đó trên Chrome của app để biết có bị captcha / chặn bot không: không bị → dùng node web (25d, chính xác nhất), bị → dùng node ảnh / chữ. Một tuỳ chọn *ưu tiên node* cho AI (mặc định ảnh / chữ), AI tự đổi được qua MCP.
  - **Chốt 2026-10-21:** nút mở + **tự dò captcha** (không chỉ mở trang); ưu tiên **2 mức**; AI đổi mức **tự do, không hỏi**, app báo nhẹ + ghi nhật ký lệnh AI. Không đổi quyết định 36: chỉ để thử trang **không cần đăng nhập** – không đăng nhập tài khoản thật trong Chrome của app (ghi chú trên hộp thử + trong guide AI).
  - [x] T1. **Dò trang** (Go, `internal/web/pagecheck.go` + `pagecheck.js` – tên `probe.js` đã dùng cho thử hover): `Chrome.CheckPage(ctx, url)` – mở tab mới, chờ `document.readyState` = complete (tối đa 15 s) + 1,5 s cho trang chạy JS / tự chuyển tiếp, trả `PageCheck`:
    - `verdict`: `ok` | `captcha` | `blocked` | `canvas` (game vẽ canvas – thêm thành kết luận riêng thay vì chỉ là dấu hiệu) | `empty`; `useWeb` = ok
    - `signs[]`: iframe captcha đang hiện (src chứa recaptcha / hcaptcha / challenges.cloudflare.com / arkoselabs / geetest…, ≥ 2 500 px²; reCAPTCHA v3 `size=invisible` chỉ ghi dấu hiệu, không tính là chặn), khối `.g-recaptcha` / `.h-captcha` / `.cf-turnstile` / `#challenge-form` đang hiện, câu kiểu "Just a moment", "Verify you are human", "Xác minh bạn là người" / "Access denied", "403 Forbidden" (thân trang chỉ xét khi chữ ≤ 1 500 ký tự – bài viết dài nhắc chữ captcha không bị nhầm), canvas ≥ 40 % khung nhìn (chỉ thành kết luận `canvas` khi < 15 phần tử), không có phần tử nào
    - `elements` (`PageOutline.Total`), `outline` ≤ 40 phần tử kèm selector, `title`, `url` (sau chuyển tiếp), `loaded`
    - `classifyPage` thuần, test bảng Go (thay cho trang mẫu trong `testdata/`) + `TestRealCheckPage` trên Chrome thật (`GHOSTHAND_REAL=1`, đã chạy qua trên Windows 2026-10-21)
    - Không đọc mã HTTP (cần theo dõi Network) – trang 403 nhận theo chữ
  - [x] T2. **Nút Thử trang** (UI): nút quả địa cầu trên thanh tiêu đề (chưa có menu Công cụ – nút riêng cạnh Cài đặt) → hộp *Thử trang trên Chrome của app*: ô URL (thiếu giao thức tự thêm https://) → Thử → ✓ Dùng được node web / ⚠ Có captcha · Nội dung vẽ trong canvas · Không đọc được gì / ✕ Trang chặn truy cập + tiêu đề, số phần tử, danh sách dấu hiệu; ghi chú "không đăng nhập tài khoản thật ở đây". `components/pagecheck/PageCheckDialog` (chỉ hiển thị) + `PageCheckButton` (state, gọi `CheckPage` – xong thì app lên lại trước Chrome); chữ theo kết luận `pageCheck.ts` có test
  - [x] T3. **Ưu tiên node cho AI** (`MCPSettings.NodePref`: `vision` mặc định | `web`, `store.SetNodePref` chỉ đổi trường này): Cài đặt → tab AI (MCP) *AI ưu tiên node: Ảnh / chữ · Trình duyệt app* (`settings/NodePrefSettings`, nhãn + chuẩn hoá trong `aiLevel.ts`). AI đổi → event `mcp:nodePref` → thông báo “AI đổi ưu tiên node sang …” (`scriptFile.ts`) + Cài đặt đang mở cập nhật; chip mức AI trên thanh mini đọc lại cài đặt trước khi lưu (không ghi đè ưu tiên AI vừa đổi)
  - [x] T4. **MCP** (`tools_web.go`):
    - `probe_page(url)` (nhóm *chạy trên máy*; mức Chỉ soạn → từ chối; chỉ http / https – `file://` sẽ cho AI đọc file trên máy qua outline)
    - `get_preferences` → `{nodePref, run}`; `set_node_preference(pref)` (nhóm mới *đổi cài đặt* – `KindSettings`, tắt được trong bảng tool 31b2)
    - `get_step_types` / `ghosthand://guide` thêm `nodePref` + `nodePrefTips` theo mức hiện tại (đọc lúc gửi); `instructions` của server thêm một dòng *Trang web: get_preferences → probe_page*
  - [x] T5. Sân thử: `captcha.html` (khung reCAPTCHA giả) + `canvas-game.html` (nút CHƠI vẽ trong canvas, bấm trúng +1 điểm) – có trong danh sách sân thử
  - [ ] Màn mẫu `#demo` có hộp Thử trang (các kết luận với dữ liệu giả) – để xem UI trên trình duyệt không cần Go
  - Chuẩn bị cho MCP (31): phần chính đã nằm trong T4
