# 44. Thử trang trên Chrome của app + ưu tiên node cho AI

- [ ] **44. Thử trang trên Chrome của app + ưu tiên node cho AI** *(người dùng yêu cầu 2026-10-21 – làm ngay, trước 42)* – Trước khi soạn kịch bản cho một trang (vd trang game A), người dùng / AI mở thử trang đó trên Chrome của app để biết có bị captcha / chặn bot không: không bị → dùng node web (25d, chính xác nhất), bị → dùng node ảnh / chữ. Một tuỳ chọn *ưu tiên node* cho AI (mặc định ảnh / chữ), AI tự đổi được qua MCP.
  - **Chốt 2026-10-21:** nút mở + **tự dò captcha** (không chỉ mở trang); ưu tiên **2 mức**; AI đổi mức **tự do, không hỏi**, app báo nhẹ + ghi nhật ký lệnh AI. Không đổi quyết định 36: chỉ để thử trang **không cần đăng nhập** – không đăng nhập tài khoản thật trong Chrome của app (ghi chú trên hộp thử + trong guide AI).
  - [ ] T1. **Dò trang** (Go, `internal/web/probe.go`): `Chrome.Probe(ctx, url)` – mở / dùng lại tab, chờ tải xong (`document.readyState` + khung đứng yên, tối đa ~15 s), trả `ProbeResult`:
    - `verdict`: `ok` (dùng được node web) | `captcha` | `blocked` (trang chặn / 403 / trống) | `error` (không mở được)
    - `signs[]` – dấu hiệu thấy: iframe reCAPTCHA / hCaptcha / Cloudflare Turnstile (`src` chứa `recaptcha`, `hcaptcha`, `challenges.cloudflare.com`), tiêu đề / chữ kiểu "Just a moment", "Verify you are human", "Xác minh bạn là người", trang trắng (ít phần tử đọc được), canvas chiếm gần hết trang (game vẽ canvas → node web không tìm được nút bên trong)
    - `elements` – số phần tử bấm / đọc được (từ `PageOutline`), `outline` rút gọn (≤ ~40 phần tử) để AI viết selector luôn, `title`, `finalUrl`
    - Hàm phân loại `classifyProbe(signs, counts)` thuần, có test bằng mẫu trang trong `testdata/` (trang thường, trang reCAPTCHA giả, Cloudflare giả, canvas game, trang trắng)
  - [ ] T2. **Nút Thử trang** (UI): menu Công cụ trên thanh tiêu đề → hộp *Thử trang trên Chrome của app*: ô URL → Thử → hiện kết quả (✓ Dùng được node web – N phần tử / ⚠ Có captcha – nên dùng ảnh / chữ / ✕ Bị chặn) + danh sách dấu hiệu; nút *Mở lại*, *Đóng tab*. Component chỉ hiển thị `components/probe/ProbeDialog.tsx` + chữ theo kết quả là hàm thuần có test (`probe/verdict.ts`); mẫu `#demo` có hộp này. Ghi chú nhỏ: "Chỉ để thử – không đăng nhập tài khoản thật ở đây (36)"
  - [ ] T3. **Ưu tiên node cho AI** (Go `MCPSettings.NodePref`: `vision` mặc định | `web`): Cài đặt → tab AI thêm `Segmented` *Ưu tiên node: Ảnh / chữ · Trình duyệt app*, kèm một dòng giải thích. Đổi (từ app hay AI) phát event cho Cài đặt + chip AI cập nhật
  - [ ] T4. **MCP**:
    - `probe_page(url)` (nhóm *chạy / đụng máy* – mở Chrome của app; theo công tắc AI: Chỉ soạn thì từ chối) → `ProbeResult` như T1
    - `get_preferences` → `{nodePref, …}` (chỉ đọc); `set_node_preference(pref)` (nhóm sửa – đổi tự do, không hỏi) → app hiện thông báo nhỏ "AI đổi ưu tiên node sang …" + ghi nhật ký lệnh AI; tắt được từng tool trong bảng tool 31b2
    - `autoclicker://guide` + `get_step_types` thêm mục theo `nodePref` hiện tại: **web** → với trang web, gọi `probe_page` trước; `ok` thì dùng node web (webWait / webClick / webType / webRead / webScroll, node Mở *Chrome của app*) với selector lấy từ `outline`; `captcha` / `blocked` / canvas → quay về ảnh / chữ và nói lý do cho người dùng. **vision** (mặc định) → giữ hướng dẫn hiện tại (tìm theo chữ, Chrome thường), chỉ thử trang khi người dùng xin. Guide đọc `nodePref` lúc gửi (không chép cứng)
  - [ ] T5. Sân thử + mẫu: thêm trang `captcha.html` (iframe giả tên recaptcha) + `canvas-game.html` vào sân thử để test T1 không cần mạng; mẫu thử dùng được với `probe_page` → node web trên trang thường của sân thử
  - Chuẩn bị cho MCP (31): đã nằm trong T4; `error.detail` của node web thêm `probe` gần nhất của trang (nếu có) để AI biết lỗi do captcha chứ không do selector
  - Kiểm tra tay: ghi vào [checks.md](../checks.md) khi xong code – thử 1 trang thường (Wikipedia), 1 trang có Cloudflare, 1 trang game canvas; đổi ưu tiên trên Cài đặt và qua Claude Code → AI chọn đúng loại node theo mức
  - Xong khi: trên Claude Code nói "ưu tiên dùng node trình duyệt, tạo kịch bản bấm nút Chơi trên trang game A" → AI gọi `set_node_preference(web)` (app báo), `probe_page` → trang không captcha thì kịch bản dùng node web; trang có captcha thì AI báo và dùng tìm theo chữ / ảnh
