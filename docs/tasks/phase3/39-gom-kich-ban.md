# 39. Gom kịch bản: nhóm node, nhúng kịch bản khác

- [ ] **39. Gom kịch bản: nhóm node, nhúng kịch bản khác** *(người dùng yêu cầu, 2026-10-19 – ưu tiên vừa: sau 22 + MCP 31, trước 24 / 28)* – Gom các đoạn kịch bản hay vào một kịch bản lớn. Thay mục *Cụm node có tên* và *subflow* của 28. Làm theo 3 mức, mức sau chỉ làm khi thật sự cần; 3 mức không phá nhau.
  - **Chốt 2026-10-19:** mức 1 → mức 2 trước (dễ, engine không đổi); mức 3 (group khoá lồng) để dành – chỉ làm khi cần gọi cùng một cụm nhiều lần với input khác hoặc MCP cần. `locked` chỉ đổi **phạm vi biến + cách sửa**, cạnh luôn qua cổng của group (bật / tắt khoá chỉ đổi một cờ, không biến đổi dữ liệu); *Bỏ nhóm* (kéo node ra phẳng) là thao tác riêng
  - [ ] G1. **Khung nhóm (cạnh nối thẳng)** – node vẫn phẳng trong `steps`; thêm `Script.Groups []Group` (`id`, `name`, `members` = id node, tuỳ chọn màu / thu gọn; `omitempty` nên file cũ mở được, không tăng `ScriptVersion` nếu app cũ bỏ qua trường lạ). Chỉ UI: vẽ khung quanh node thành viên, đặt tên, kéo cả cụm, thu gọn thành một thẻ (cạnh vào / ra nối vào thẻ thu gọn), chọn nhiều node → *Nhóm lại*, *Bỏ nhóm*; xoá node thì bỏ khỏi `members`. Engine, `FlowOrder`, biến, lỗi, lịch sử chạy không đổi
  - [ ] G2. **Nhúng kịch bản khác (phẳng)** – chọn file kịch bản (hoặc kịch bản mẫu) → chép node + cạnh vào kịch bản đang soạn thành một khung nhóm G1. Hàm thuần làm một lần lúc nhúng (Go hoặc TS, có test): đổi `id` / `ref` trùng, viết lại `{{n2…}}` / `ImageFrom` / `Start` / cạnh theo tên mới, **quy đổi toạ độ** theo `Region` / `AnchorMode` của kịch bản con sang vùng kịch bản cha, node `end` success → nối tiếp ra ngoài (fail giữ dừng kịch bản), input của kịch bản con → gộp vào input kịch bản cha (trùng key thì hỏi). Ảnh mẫu base64 đi theo node. Bản nhúng không tự cập nhật khi sửa file gốc (ghi `from` trong group để biết nguồn)
  - [ ] G3. **Group khoá (lồng) – để dành** – node `group` có thân riêng (`Steps / Edges / Start`, input, `Region` riêng), cổng `success` / `fail`, output lấy từ node `end` bên trong; `locked`: bên trong chỉ thấy input của group, bên ngoài chỉ thấy output (không khoá: đọc xuyên `{{g1.n3.output…}}`, sửa ngay trên canvas). Nặng ở engine (chạy flow lồng, input thay lúc chạy), đường dẫn node `g1/n3` cho lỗi / điểm dừng / chạy riêng / Xem trước / lịch sử, canvas mở vào trong group; *Khoá nhóm* chuyển khung G1 thành group. Tăng `ScriptVersion`. Trước khi làm: hỏi lại người dùng còn cần không
  - Chuẩn bị cho MCP: G1 / G2 không đổi engine / lỗi – AI chỉ cần biết `groups` để sửa theo cụm; G3 đổi định danh node (đường dẫn) – nếu làm thì làm trước khi MCP ổn định
  - Kiểm tra tay: ghi vào [checks.md](../checks.md) khi xong code – nhóm / bỏ nhóm / thu gọn trên canvas; nhúng một kịch bản mẫu vào kịch bản có vùng khác → click đúng chỗ; biến trong đoạn nhúng chạy đúng
