## 1. Bức tranh tổng

```
┌──────────── Frontend (React/TS, WebView) ────────────┐        ┌──────── Go: main (root – chỉ Wails) ─────────┐
│ screens/  MainScreen · OverlayScreen · MiniBar ·     │ gọi    │ App (app.go) – method public = API bind,     │
│           PreviewScreen · Demo* (hash URL chọn màn)  │──────► │   mỗi method vài dòng gọi xuống internal/    │
│ components/ (chỉ hiển thị + gọi hàm store)           │ Wails  │ runner.go · storage.go · imageapi.go ·       │
│ store/ (kịch bản đang soạn, hoàn tác)                │ bind   │ window.go · hotkey.go (gohook F6/F8/F10)     │
│ engineStore · runStore · runForm · scriptFile ·      │◄────── ├──────────────── internal/ ───────────────────┤
│ imageSteps · coordMap · windowMode                   │ events │ engine  chạy flow (node, biến, thử lại)      │
│ flow/ anchor.ts transform.ts (logic thuần, có test)  │        │ script  đọc / kiểm tra kịch bản, input, neo  │
└──────────────────────────────────────────────────────┘        │ store   cấu hình, file, nháp, lịch sử chạy   │
                                                                │ device  chuột / phím, chụp, OCR (interface)  │
                                                                │ vision  tìm ảnh / chữ   launch  mở URL / app │
                                                                │ web     Chrome của app qua CDP (node web)     │
                                                                │ model   kiểu dữ liệu (mọi package dùng)      │
                                                                └──────────────────────────────────────────────┘
```

- **Một cửa sổ Wails** (frameless, nền trong suốt). Overlay / mini bar = đổi cỡ + vị trí + always-on-top cửa sổ đó (`SetWindowMode`), frontend đổi `location.hash` → `App.tsx` chọn màn. Các màn **không cùng mount** → state dùng chung nằm trong store module (`useSyncExternalStore`), không trong React state.
- **Go là nguồn chuẩn model**; frontend gọi Go qua `frontend/wailsjs/go/main/App` (tự sinh), Go đẩy trạng thái về qua `runtime.EventsEmit`.
- **Trình duyệt không có Go** (`inWails = false`): store nạp dữ liệu mẫu, nút Chạy tắt – dùng để xem UI.

## 2. Model (`internal/model`: model.go, flow.go)

- `Script` = `{version(4), name, region(nil = màn chính), loops(0 = vô hạn), maxMinutes, steps[], start, edges[], anchorMode, inputs[]}`.
- `Step` = **node**. Định danh bằng `id` (cạnh, `start`, `imageFrom` trỏ theo id); `ref` (`n2`) chỉ để hiển thị + biến. Thứ tự mảng `steps` **không** quyết định thứ tự chạy.
- `Edge{from, port, to}` – mỗi cổng tối đa một cạnh. Cổng theo loại (`portsOf`, Go + TS cùng công thức):

| Loại | Cổng ra |
|---|---|
| hành động (click, double, hold, drag, wait, type, key, scroll, open, browserTab, browserGo, browserNorm, waitImage, clickImage, waitPixel, webWait, webClick, webType, webRead, webScroll, elementRead) | `success`, `fail` |
| `if` | `true`, `false` |
| `switch` / `switchScreen` | `case:<key>`… + `default` / `none` |
| `counter` | `next`, `done` |
| `forEach` | `item`, `done` |
| `app` (`appOp` trống = kiểm tra) | `yes`, `no` – thao tác khác `success`, `fail` |
| `setVar` | `success` |
| `end` | (không có) |

- `Point{x, y, ax, ay}` – toạ độ **trong vùng**, mỗi trục neo `start|end|center|ratio` (`script/anchor.go` ↔ `anchor.ts`). Đổi ra toạ độ màn hình lúc chạy bằng `script.ResolvePoint` trên khung `script.StepBounds` (↔ `stepBounds` / store `boundsOf(region, step)`): node có `coordSpace: "absolute"` (46 A1 – điểm AI đọc từ screenshot) tính theo gốc màn hình, không cộng gốc vùng, đổi vùng không dời. Có `xVar` / `yVar` (F5b) → điểm dùng biến: toạ độ **màn hình** tính lúc chạy (`script.PointOnScreen` / `EvalCoord` – số / biến cộng trừ px), bỏ qua x / y + neo; frontend `usesVar` – không marker, không chọn nhiều (`endpoints` trả null).
- `StepResult{nodeId, ref, status, port, output, error{code,message,detail}, logs, attempts, loop, shot}` (`detail` – chi tiết có cấu trúc cho AI: chỗ khớp nhất / dòng chữ đọc được kèm khung / màu thật / phần tử – cửa sổ – app gần giống / trạng thái tìm web + `context` cửa sổ trước, chuột, màn hình – `engine/detail.go`) – kết quả mỗi lần chạy node. Mã lỗi: `not_found`, `timeout`, `permission`, `invalid_input`, `cancelled`, `end`, `browser` (Chrome của app chưa mở / mất kết nối), `internal`.
- Output theo loại (đầy đủ ở `internal/model/steptypes.go`): chờ / click ảnh·chữ → `x, y, w, h, score(, text)`; waitPixel → `color`; webWait / webClick / webScroll → `x, y, w, h, text, selector` (+ `clickX, clickY`; webScroll tới khi thấy + `scrolls`); webType → `text` (đã gõ) + chỗ click; webRead → `text` (giá trị đọc), `count`, `selector`; if → `result` + chỗ thấy; end thành công → `message`.

## 3. Luồng soạn kịch bản

```
component ──gọi──► store/nodes|control|points|multi ──► flow/edit.ts (logic thuần) ──► updateScript()
                                                                                      │ push past[], bật dirty
                                                                                      ▼
                                       listeners → mọi màn re-render;  scriptFile.ts ghi nháp (giãn 800 ms) → SaveDraft
```

- Mọi sửa kịch bản đi qua `updateScript` (`store/editor.ts`) → có hoàn tác / làm lại + cờ chưa lưu (`SetEditorState` báo Go file + cờ chưa lưu – hỏi khi đóng, AI không ghi đè bản đang dở).
- Thêm node: bảng Ctrl/Cmd+K (`AddStepPalette`) → `addStep` (mặc định theo loại ở `flow/defaults.ts` – giống Go `NewStep`; cũng dùng cho mục *Về mặc định* của ô số) / `addControl` → nối vào node đang chọn (`insertAt`).
- Canvas: `FlowEditor` (nối store) → `FlowHeader` (dòng đầu đè trên canvas) / `FlowCanvas` / `NodeCard` / `FlowEdge` (chỉ props). Tên, chi tiết, nhãn cổng, output gợi ý lấy từ `flow/view.ts`; nhóm node (màu đầu thẻ, nhóm trong bảng thêm node) từ `flow/category.ts` (`nodeCategory`, class `cat-<nhóm>` + `bg-cat-soft` / `bg-cat-tile` / `text-cat`). Cỡ thẻ + vị trí cổng: `components/flow/model.ts` (`nodeHeight`, `portY`, `portRows`). Tự xếp: `flow/layout.ts` (elkjs nạp lười).
- Inspector: `StepForm` → trường theo loại ở `components/stepform/*`, node điều khiển ở `components/flow/nodes/*` (qua `stepform/ControlSection`).

### Đặt điểm / vùng trên overlay

1. `openOverlay(tool, focus)` (`windowMode.ts`) → Go `OverlayDisplayFor` chọn màn chứa vùng → `SetWindowMode('overlay')` → hash `#overlay`.
2. `OverlayScreen` vẽ vùng + marker; click → toạ độ cửa sổ → **`coordMap.ts`** đổi sang toạ độ robotgo (ước lượng `k, b` từ mẫu `MousePos`, xử lý DPI / màn phụ) → `store/points` đổi sang điểm neo theo vùng (`store/geometry`).
3. F6 (Go `hotkey.go`) → event `hotkey:f6 {x,y}` (toạ độ robotgo sẵn) → `store/points` thêm điểm.
4. Công cụ: `point`, `drag` (A rồi B), `region`, `preview` (con trỏ giả – `Simulation.tsx`, đi theo đồ thị: cổng ở node rẽ nhánh chọn trong menu Nhánh – `flow/preview.ts`, `previewBranches.ts`), `select` (biến đổi nhiều điểm – `TransformTool` + `transform.ts`), `capture` (khoanh ảnh mẫu – `imageSteps.ts` → Go `CaptureTemplate`, ẩn cửa sổ lúc chụp).

### Lưu / mở (storage.go → `store` / `script` ↔ scriptFile.ts)

- File `.json` (`ScriptVersion` = 4; cũ hơn từ chối, không chuyển đổi). Mở: `store.ReadScriptFile` → `script.DecodeScript` → `checkScript` (chỉ sửa cấu trúc: ref trùng, cạnh hỏng…) – **không** `validateScript` (bản soạn dở vẫn mở được).
- Nháp `draft.json` (kịch bản + path + dirty) – mở app nạp lại. Đóng app khi dirty: `beforeClose` chặn → event `app:confirmClose` → `SaveChangesDialog` → `ConfirmQuit`.
- Thư mục cấu hình `os.UserConfigDir()/ghosthand/`: `settings.json` (theme, mở gần đây), `draft.json`, `inputs.json` (giá trị input lần trước / preset theo kịch bản), `runs/<tên>-<hash path>/` (lịch sử chạy), `sandbox/` (trang sân thử của Mẫu thử, ghi đè mỗi lần mở mẫu).
- **Nơi lưu** (bước 41, `store/storagedirs.go`): `Settings.Storage` (`scriptsDir`, `aiScriptsDir`, `shotsDir`; trống = mặc định `DefaultDirs` – Documents / Pictures + `Ghosthand`, Windows qua `SHGetKnownFolderPath` trong `knownfolder_windows.go`). `ScriptsDir` – hộp thoại Lưu lần đầu / Mở; `AIScriptsDir` – MCP `create_script` (trống = theo `scriptsDir`); `ShotsDir` → `session.Deps.ShotsDir` → `engine.Options.ShotsDir` (node Chụp màn hình để trống `saveDir`). Thư mục đã chọn không còn → lỗi gợi ý *Về mặc định*, không tự đổi chỗ. Cài đặt → tab Lưu trữ (`settings/StorageSettings`).
- Mẫu thử (bước 33): `OpenSample` → `samples.Open` (qua `DecodeScript` như file) → `scriptFile.openSample` mở như kịch bản mới chưa có file (hỏi lưu nếu đang dirty).

## 4. Luồng chạy

```
Bấm Chạy / F8 (hotkey:f8start)
  └► runForm.startRun: có input & chưa "chạy luôn" → RunDialog (preset, giá trị lần trước) ; không thì chạy ngay
      └► engineStore.runScript
           1. Go ValidateScript(sc, values)   — lỗi: ở lại màn chính, hiện lastError
              Go DangerCheck(sc, values, path) — có thao tác nguy hiểm (xoá file, buộc thoát app, đóng cửa sổ) chưa đồng ý → DangerConfirmDialog (Huỷ = không chạy)
           2. setWindowMode('minibar')
           3. Go RunScript(sc, values, session.Options{countdown, path, source, preset, from, only, step, confirmDanger})   (= Start + Wait, chặn tới khi xong)
           4. setWindowMode('main')
```

**Bên Go – phiên chạy `internal/session` (bước 22):** mọi nguồn (nút Chạy, API local, CLI, hẹn giờ, sau này MCP) gọi `Manager.Start` → trả `runId` ngay; `Wait` / `Status` / `Stop` theo `runId`, một lúc một phiên (`ErrBusy`). `runner.go` chỉ còn method mỏng. Event qua `Emitter` (`App.emit` → Wails + hub SSE của API).
1. `script.ResolveInputs` – thay `{{key}}` input vào **bản sao** kịch bản; `script.ValidateScript` (flow: `validateFlow`, rồi từng node).
2. `session.AllowDanger` (thao tác nguy hiểm đã đồng ý chưa – chặn cả nguồn ngoài app); `exec.go`: `engine.New(device.TrackingInput{Deps.Input}, sc, engine.Options{…, Browser: Deps.Browser})` (thiết bị qua `session.Deps` – test bằng bản giả); `run:started` (nối Chrome lười – kịch bản không có node web thì không đụng); đếm ngược (`engine:countdown`); bật `device.WatchCorners` (chuột chạm góc → dừng, `engine:stopped "corner"`).
3. `Engine.Run` (`internal/engine/flowrun.go`) → mỗi vòng `runLoop`: từ `start`, lặp:
   - `breakBefore` (debug: breakpoint / chạy từng node → chờ Tiếp / F10)
   - `execNode`: node tắt → `skipped` đi `success`; `resolveNodeVars` (biến `{{n2.output.x}}`, `{{last.…}}`, `{{vars.x}}` – thiếu biến → `invalid_input`); node điều khiển → `runControl` (`nodes.go`, `cond.go` xét điều kiện, chụp một lần mỗi lần xét); node hành động → `runStep` (`actions.go` `doStep`, ảnh / pixel / chữ ở `imagestep.go` + `internal/vision`, web ở `webstep.go` / `webactions.go` + `internal/web`); lỗi thì thử lại theo `Retry` (node hành động).
   - Thất bại → chụp màn (`shoot`, `shots.go`). Gửi `engine:node` (StepResult). Đi theo `edgeOut(port)`; `fail` không nối → dừng báo lỗi (`engine:failed`); cổng khác không nối → xong vòng. Thành công → chờ `delayAfter ± jitter`.
   - Quá 10 000 node / vòng → lỗi lặp vô hạn. Kết quả + biến đặt lại mỗi vòng.
4. `Deps.SaveRun` → `store.SaveRun`: `runs/…/<runId>.json` + ảnh lỗi (giữ 50 lần) → `engine:done` (RunSummary), `engine:state false`, `run:ended` (Status), `Manager.OnEnd` (hẹn giờ gửi thông báo).

Dừng / tạm dừng: `StopScript` (huỷ ctx), `PauseScript` / `ResumeScript` / `StepScript` (F10) qua `pauseGate` (`engine/gate.go`). F8 lúc đang chạy = dừng (`engine:stopped "f8"`).

**Frontend nhận:** `engineStore` (state, countdown, progress, failed, stopped, hotkey:error) → MiniBar / thanh trạng thái; `runStore` (engine:node, engine:done) → canvas tô trạng thái node + cạnh đã đi (`flow/run.ts`) + `RunLog`; `imageSteps` (engine:failed kèm chỗ giống nhất) để xem lại ảnh mẫu.

### Các đường chạy phụ

- **Thử node** (`TestNode` → `Engine.TestNode`, `engine/nodetest.go`): xét if / switch / switchScreen trên màn hình lúc này, không chạy cả flow → `NodeTestPanel` + khung chỗ thấy trên overlay.
- **Thử tìm ảnh / chữ / phần tử** (`FindImage` → `Engine.FindOnce`), **Chọn phần tử trên màn** (37 E3: `PickElementAt` → `Engine.PickElement`, `engine/elementpick.go` + `element.At` / `QueryFor`; overlay lấy điểm qua `pickScreenPoint` – `store/points.ts`, `pickElement` – `imageSteps.ts`), **lấy màu** (`PixelColorAt`), **quyền chụp** (`ScreenCaptureAllowed` / `RequestScreenCapture`, macOS Screen Recording).
- **Node web** (`webapi.go`, một `web.Chrome` riêng của giao diện): trạng thái Chrome của app (`BrowserStatus`), mở trang trống (`OpenAppBrowser`), **Thử tìm** (`FindElement` → `Engine.FindElement`, `engine/webfind.go`), **Chọn phần tử trên trang** (`PickElement` / `CancelPick` → `Chrome.Pick`, `web/pick.go` + `pick.js`) → `webSteps.ts` + `stepform/WebTools`. **Thử trang** (44: `CheckPage` → `Chrome.CheckPage`, `web/pagecheck.go` + `pagecheck.js` – mở trang, dò captcha / chặn bot / canvas; url rỗng = Dò lại tab đang mở) → nút quả địa cầu trên `TitleBar` (`components/pagecheck/`, chữ theo kết luận `pageCheck.ts`).
- **Chạy từ node**: `RunOptions.from` → một vòng bắt đầu ở node đó (biến node trước trống); thêm `only` → chạy riêng node đó (`script.RunFrom` bỏ cạnh ra của nó). **Chạy một phần** (31b, `session.Options`): `stopAt` (chạy xong node đó thì dừng – `Status.reached`), `nodes` (chỉ cụm – `script.RunPart` giữ cạnh trong cụm), `seedRun` (kết quả node + biến của lần chạy trước – `engine.Carry` nạp vào đầu vòng 1: chạy tiếp từ node lỗi), `maxMinutes` (trần lượt AI – hết giờ thì `Status.timedOut`). `Manager.Trace` – kết quả từng node + input + ảnh lỗi trong bộ nhớ (20 lần gần nhất).
- **Lịch sử**: `ListRuns` / `GetRun` / `RunShot` – mở từ thư viện, hiện như lần chạy đang xem; `DeleteRun` / `ClearRuns` (bước 41) xoá một / mọi lần chạy – `runStore.deleteRuns`, nút ở `library/RunsDelete`.
- **Chạy từ ngoài app** (bước 22): API local `internal/api` (chỉ 127.0.0.1 + Bearer token; `/run` `/stop` `/status` `/events` SSE `/script` có revision) – kênh cho CLI luôn bật (cổng ngẫu nhiên, `api.json`), cổng cho chương trình khác theo Cài đặt (`apiserver.go`). CLI `ghosthand run <file>` (`internal/cli`, `main.go` rẽ trước Wails) gửi sang app, chưa mở thì mở. Hẹn giờ: `internal/schedule` (`Due` / `Loop` nhịp 15 s, `model.NextRun`) → `scheduleapi.go` `fireSchedule` → session, xong thì `internal/notify` (Telegram / Discord / webhook + ảnh màn hình). Nguồn khác `user` → frontend tự thu thanh mini (`engineStore` nghe `run:started` / `run:ended`).
- **AI qua MCP** (bước 31): `internal/mcpsrv` – route `/mcp` (stateless, trả JSON) gắn vào API local, nên có trên cả kênh CLI lẫn cổng cho chương trình khác; `ghosthand --mcp` (`internal/cli/mcp.go`, `main.go` rẽ trước Wails) đọc JSON-RPC từng dòng ở stdin → POST /mcp của app (chưa mở thì mở). Tool đọc / ghi qua `mcpsrv.Backend` (`mcpapi.go`): kịch bản gửi dạng gọn `script.Compact` → `Expand` → `Checked`; sửa = `script.Patch` / `ApplyPatch`; ghi qua `writeScriptExternal` (source `ai`); kịch bản đang mở có thay đổi chưa lưu (`SetEditorState`) → ghi bản sao; `open_in_app` → event `mcp:open` → `scriptFile.ts` mở như *Mở gần đây*. Công tắc trong Cài đặt (`store.MCPSettings` – `enabled` + mức chạy `run` edit | ask | auto + `maxMinutes`). **Vòng thử – sửa** (31b): `run_script` / `wait_run` / `stop_run` / `resume_run` (`tools_run.go`, vết chạy gọn + ảnh lỗi – `trace.go`), `describe_screen` / `screenshot` (`tools_screen.go`); **thử trang + ưu tiên node** (44): `probe_page` / `read_web_outline` / `get_preferences` / `set_node_preference` (`tools_web.go`) – `MCPSettings.nodePref` vision | web, guide (`get_step_types`) kèm `nodePrefTips` theo mức, AI đổi → event `mcp:nodePref` (thông báo + Cài đặt cập nhật); `mcprun.go` – `Backend.Run` hỏi quyền (event `ai:ask` → `AIRunDialog` → `AnswerAIRun`) rồi `session.Start` nguồn `ai`. `--mcp` mở app bằng `--background` (`StartHidden`): AI chạy thì chỉ hiện thanh mini, xong giữ thanh mini (`InBackground`).
- **Kịch bản bị ghi từ ngoài** (API `PUT /script`, AI qua MCP): `writeScriptExternal` (kiểm tra như lúc mở file, `store.Revisions` – sai revision → `conflict`) → `script:changed` → `scriptFile.ts` nạp lại file đang mở bằng `reloadScript` (bản đang soạn vào hoàn tác).
